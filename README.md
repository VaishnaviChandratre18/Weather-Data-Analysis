**Weather Data Analysis** 



Analyzed 90 days of weather data using Python (pandas, NumPy, Matplotlib, Seaborn) to explore temperature, humidity, wind speed, and rainfall patterns, and derive actionable insights.



*About the project*



This project covers the full data analysis workflow on a weather dataset — cleaning raw data, calculating key statistics, grouping data by month, and visualizing trends through line charts, histograms, boxplots, scatter plots, and a correlation heatmap. The analysis identifies temperature extremes, rainfall patterns, and relationships between weather variables, wrapping up with a short insights summary.



&#x20;*Dataset*

\- 90 days of data across 5 columns: Date, Temperature, Humidity, WindSpeed, Rainfall

\- Date range: 1 Jan 2024 – 30 Mar 2024

\- No missing values or duplicates



*Approach*

\- Cleaned and explored the weather data

\- Calculated summary statistics and identified hottest/coldest days

\- Analyzed monthly trends across temperature, humidity, wind speed, and rainfall

\- Visualized patterns using line charts, histograms, boxplots, scatter plots, and a correlation heatmap

\- Checked for outliers and relationships between variables

\- Summarized findings into key insights



*Tools used*



Python ,Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook



*Key insights*



\- Average temperature: 27.7°C (hottest: 33.6°C on 1 Feb, coldest: 20.1°C on 15 Mar)

\- Average humidity: 66%, fairly stable across the period

\- Average wind speed: 13 km/h, with a slight increase month over month

\- Average rainfall: 2.4mm/day, with February recording the most rainfall

\- Temperature, humidity, wind speed, and rainfall showed very weak correlation with each other, indicating they vary largely independently

\- No outliers detected — all values fall within realistic weather ranges
